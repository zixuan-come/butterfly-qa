## 当前工作项：T06

### 目标

实现主流程 Agent 的调用契约与调度边界，将状态机、结构化校验和产物存储连接起来。

### 本次范围

- 定义统一的 Agent 请求和响应协议。
- 根据当前流程状态选择对应的 Agent 和 Skill。
- 校验 Agent 输出，保存产物并推进流程状态。
- 调用失败时保留当前状态并生成可诊断错误。

### 完成标准

- 主流程不依赖自由文本判断 Agent 是否执行成功。
- 专业 Agent 不直接互相调用，所有交接经过主流程。
- 非法状态跳转和不合格产物不会进入下一阶段。
- 调用过程可以使用测试替身，不依赖真实模型完成单元测试。
- 不引入 RAG、数据库、Web 后台或接口自动化等 V1 外能力。
